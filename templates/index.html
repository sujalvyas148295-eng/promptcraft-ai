Introduction to Prompt Engineering

Understanding the core principles that separate vague queries from high-performance AI responses.

“
Prompt engineering is the process of writing clear instructions and providing useful context so an AI tool can better understand what you want.
— IPE Course Core Definition
🎯

1. Clarity

State the exact task with direct, unambiguous action verbs. Eliminate ambiguous phrasing, conflicting objectives, and unnecessary filler words.

"Build a responsive navbar" instead of "Make some web stuff"
🌐

2. Context

Provide the background setting, persona, target audience, and domain boundaries so the AI assumes the proper tone, depth, and framing.

"Act as a Senior Python Architect writing code for college students"
🛡️

3. Constraints

Define what the AI must do and what it must NOT do (negative prompts, aspect ratios, word caps, language constraints, and edge case rules).

"No external libraries; limit to pure standard library modules"
📋

4. Output Format

Instruct the AI exactly how to structure its final answer: Markdown tables, JSON schemas, numbered steps, or copyable code blocks.

"Format output as a 3-column table: Concept, Analogy, Code"

Vague Prompt vs. PromptCraft AI Engineered Prompt

❌ Vague Amateur Prompt

"Give me a futuristic city picture with rain."

  • Undefined camera angle and lens depth
  • No lighting, color palette or aesthetic instructions
  • Prone to muddy, blurry or cartoonish AI hallucinations
  • Zero control over aspect ratio or resolution
✨ PromptCraft AI Prompt

"Sprawling neo-Tokyo metropolis at midnight, volumetric neon rim lighting, 50mm f/1.4 prime lens, octane render, 8K UHD, electric cyan and deep violet palette --ar 16:9 --v 6.1"

  • Precise camera parameters and lighting depth
  • Art-directed color palette and master resolution
  • Explicit negative constraints preventing blurry artifacts
  • Ready-to-copy parameter syntax for production models
